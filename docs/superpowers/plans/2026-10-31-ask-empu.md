# Ask Empu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menambahkan pintu tanya-jawab "Ask Empu" yang menjawab hanya dari entri kamus yang ada, dan menampilkan klip, crop, kutipan, label sumber, serta waktu sebagai bukti — untuk pembaca publik dan untuk pendokumentasi di Studio.

**Architecture:** Satu modul `api/empu/ask/` yang mengambil entri sesuai cakupan, menyaringnya secara leksikal, memanggil Muse sekali lewat `MetaClient.respond_text` dengan structured output berisi id sitasi, memvalidasi id, lalu menghidrasi bukti dari DB memakai serializer yang sudah ada. Dua route tipis: publik tanpa kunci dan Studio dengan `X-Studio-Key`. UI Next.js memanggil rewrite same-origin `/api/*` dan `/media/*`.

**Tech Stack:** Python 3.12, FastAPI, SQLModel/SQLite, Pydantic v2, rapidfuzz, httpx + respx, pytest, ruff. Next.js 16.4 (App Router), TypeScript, Tailwind 4, vitest.

**Spec:** `docs/superpowers/specs/2026-10-31-ask-empu-design.md`

## Global Constraints

Berlaku untuk setiap task. Disalin dari `docs/superpowers/plans/2026-10-28-empu/00-ikhtisar.md` dan spec desain.

- **AI mengusulkan, manusia memutuskan.** Pintu publik hanya memakai aturan `empu.visibility` (`public_entries`, `public_occurrences`, `entry_is_public`). Jangan menulis ulang aturan visibilitas.
- **Bukti selalu terlihat.** Respons tanpa `entry_ids` valid tidak boleh menampilkan bukti apa pun dan harus `refused=true`.
- **Label sumber tidak boleh hilang.** Setiap baris indeks dan setiap kartu bukti membawa `speech` / `on_screen_text` / `visual_only`.
- **Gambar hanya dari frame asli.** Tidak ada pembuatan gambar. Model hanya menerima teks, bukan video atau gambar.
- **Semua panggilan Meta lewat `api/empu/meta_client.py`.** Cache respons memakai `empu.cache.ResponseCache`; jangan memanggil API kalau cache ada.
- **Rahasia:** `META_MODEL_API_KEY` dan `STUDIO_KEY` tidak boleh dicetak, di-log, atau di-commit. Hanya `api/empu/config.py` yang membaca env.
- **Pengetahuan keterampilan hanya di craft pack.** Tidak boleh ada istilah batik di `api/empu/**`; `api/tests/test_no_hardcoded_terms.py` harus tetap hijau. Prompt hanya berisi baris data.
- **Tes tidak boleh memanggil API sungguhan.** Pakai `respx`, `FakeClient`, atau fungsi palsu.
- Setiap perubahan teks prompt menaikkan `ASK_PROMPT_VERSION`.
- Kode dan identifier bahasa Inggris; UI bahasa Inggris; dokumen `docs/` bahasa Indonesia.
- Tes API: `TestClient` + SQLite sementara. Frontend: `pnpm lint`, `pnpm test`, `pnpm build`.
- Jangan menyentuh `data/`, `data-uji/`, `arsip-hidup-batik/`, atau video.

## Review Focus

Lima hal yang paling mungkin melukai pengguna dan tidak otomatis tertangkap oleh tes bahagia:

1. **Kebocoran bukti belum tervalidasi.** Pertanyaan menyebut istilah yang ada sebagai `proposed` → pintu publik tidak boleh menampilkan atau menyitir bukti dari entri itu. (Task 7)
2. **Pertanyaan di luar arsip.** "Bagaimana mencelup dengan indigo?" saat arsip tidak memuatnya → `refused`, bukti kosong, tanpa istilah karangan. (Task 6, 7)
3. **Izin dicabut setelah jawaban di-cache.** Cache hit tidak boleh menampilkan bukti dari rekaman yang kini `withdrawn`. (Task 6)
4. **Bahasa penanya.** Pertanyaan berbahasa Indonesia/Jawa harus dijawab dalam bahasa itu, bukan Inggris. (Task 4 prompt, Task 10 verifikasi manual)
5. **Arsip kosong.** Tidak boleh memanggil model, tidak boleh 502; harus `refused` yang tenang. (Task 6)

### Task 6: Mesin jawaban

**Files:**
- Create: `api/empu/ask/engine.py`
- Modify: `api/empu/ask/__init__.py`
- Test: `api/tests/test_ask_engine.py`

**Interfaces:**
- Consumes: `build_index`, `prefilter`, `build_prompt`, `ASK_PROMPT_VERSION`, `ResponseCache`, `AnalyzeResult`, `public_entries`, `public_occurrences`, `entry_is_public`
- Produces:
  - `class AskError(RuntimeError)`
  - `@dataclass(frozen=True) Cited: entry: Entry; occurrences: list[Occurrence]; occurrence: Occurrence`
  - `@dataclass(frozen=True) AskResult: answer: str; lang: str; refused: bool; entry_ids: list[int]; evidence: list[Cited]; model: str; prompt_version: str; cached: bool; usage: dict`
  - `collect_entries(session: Session, archive_id: int, scope: str) -> list[tuple[Entry, list[Occurrence]]]`
  - `answer_question(session: Session, *, archive_id: int, question: str, scope: str, ask_model: Callable[[str], AnalyzeResult], cache: ResponseCache, model: str, pack_name: str, max_entries: int = 60) -> AskResult`

Aturan `collect_entries`: `scope == "public"` → `public_entries(session, archive_id)` (jangan duplikasi aturan). `scope == "studio"` → entri arsip dengan status bukan `rejected`/`merged`; kemunculan hanya dari rekaman `consent_status == granted` dan bukan `OccurrenceStatus.rejected`; entri tanpa kemunculan dibuang; urut `term.casefold()`.

Aturan `answer_question`: normalisasi `" ".join(question.split())`; arsip kosong → `refused=True` tanpa memanggil model dan `answer = REFUSAL_NO_ENTRIES`; kunci cache = `cache.key(sha256(f"{scope}|{archive_id}|{q.casefold()}"), model, ASK_PROMPT_VERSION, scope)`; `res.parsed is None` → `AskError`; id divalidasi terhadap baris yang dikirim; `insufficient` atau tanpa id valid → `refused=True`, `entry_ids=[]`; hidrasi selalu dari DB menjadi `Cited` (semua kemunculan dalam cakupan + kemunculan terpilih: `best_occurrence_id` bila ada, jika tidak yang pertama); bila hidrasi kosong → `refused=True`; bila `refused` → `evidence=[]`.
